# Changelog

## 0.0.2

Published to npm as `@actera-ai/sdk`. Imports change from `@actera/sdk`, the name
the 0.0.1 GitHub archive used, to `@actera-ai/sdk`. The API is unchanged.

## 0.0.1

Initial alpha release of the Actera TypeScript SDK: agent-bound decisions and
execution reports, managed execution with a host-supplied dispatcher, and MCP
interception with approval continuation. The public API can change between
minor versions before 1.0. Released only as a GitHub archive, as `@actera/sdk`.
